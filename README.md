# 象库 · ONTO Lab
> 你的知识，掌握在我。个人结构化知识引擎与论证工坊。

象库（ONTO Lab）是一个基于 **本地优先（Local-First）** 理念构建的轻量级单文件知识库与写作工作台。它专为深度研究、学术祛魅、概念沉淀与严肃写作设计，拒绝笨重的工程依赖，以单 HTML 文件的形式实现多空间管理、智能档案检索与严谨论证闭环。

---

## 核心架构与功能特性

### 1. 多空间知识仓储（Multi-Space Storage）
- **独立知识空间**：支持建立多个彼此隔离的知识单元，各自拥有专属的档案库、草稿台与问答记忆。
- **多模态纯前端解析**：
  - 支持 `.txt`、`.md` 纯文本入库。
  - **原生 PDF 文本解析**：内置 `PDF.js`，浏览器端直接提取 PDF 全文为纯文本，零服务端依赖，彻底杜绝数据臃肿与编码乱码。
  - **网页链接抓取**：一键抓取并清洗网页核心正文。
  - **剪贴板导入与标签矩阵**：支持自由打标、快速筛选与全库全文检索。

### 2. 论证工坊（Workshop）
- **双层写作视图**：
  - **Outline（逻辑骨架）**：提供“先承重后填肉”的结构化大纲视图，支持 AI 结合库内档案一键提炼论证骨架。
  - **Draft（正文草稿）**：沉浸式草稿写作台，草稿与空间本体解耦。
- **定稿入库机制**：写完文章一键“定稿入库”，自动生成带时间戳与版本的正式篇章沉淀至 Library，解决草稿覆盖与历史归档问题。

### 3. 双轨 AI 交互引擎（OpenAI 兼容接口）
- **Nik · 档案员（空间专属智库）**：
  - 严格基于当前空间的真实档案进行事实核验与推理。
  - 内置**智能检索（Smart Retrieval）**机制，先基于问题向量初筛关联卷宗，再由档案员进行跨章节研读并明确标注文末出处。
  - 空间问答流物理隔离，切换空间自动加载对应研读记录。
- **Nik · 审阅机器人（学术与逻辑质检）**：
  - 以对话形式融入侧边栏，针对草稿进行冷酷质检：排查论证跳跃、缺乏依据的主观断言、用词冗余与概念不自洽，并输出结构化批注清单。
- **Nik · 全域助手（悬浮抽屉）**：
  - 随时拉出全域对话框，支持宽泛的哲学探讨、日常发散与全网思维激荡。

### 4. 插件生态扩展（Obsidian-like Ecosystem）
- **思维导图插件（Mindmap）**：一键将当前空间的知识脉络提炼为可交互的树状可视化导图，并支持复制 Markdown 树。
- **PPT 演示文稿插件（Presentation）**：将档案与草稿自动转化为标准 5-8 页幻灯片大纲，支持一键导出 **Marp 格式 Markdown**，无缝接入各类排版工具。

### 5. 随手记与数据安全（Data Sovereignty）
- **Scratchpad（随手记）**：常驻轻量灵感便签，自动保存草稿并保留最近 200 条历史，支持一键将碎片闪念归档至当前知识空间。
- **本地自治与坚果云备份**：数据全量存储于浏览器本地，不上传第三方服务器；提供标准 `.json` 导出/恢复接口，便于配合坚果云、WebDAV 或本地网盘实现跨设备增量同步。

## 技术栈与运行方式

* **单文件架构**：纯静态 `HTML + Vanilla JavaScript + Tailwind CSS CDN`，无需 `npm install`，无需构建环境，双击即可在任何现代浏览器中运行。
* **图标与核心组件**：`Lucide Icons`、`JSZip`、`PDF.js`。
* **API 兼容**：兼容 DeepSeek、OpenAI 等所有标准的 OpenAI 兼容 API 接口。

---

## 快速使用

1. 下载仓库中的 `index.html`。
2. 在浏览器中直接打开。
3. 点击右上角 **设置（⚙️）**，填入你的 API Key、接口地址（默认 DeepSeek）及模型名称。
4. 新建空间，开始导入档案与深度写作。
